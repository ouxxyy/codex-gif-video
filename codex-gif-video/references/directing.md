# 短 GIF 分镜写法

给每个镜头一个观众能看见的变化。写“纸盒压弯了最下面的盒盖”，比写“工作压力很大”更容易决定起始姿势、接触点和收尾画面。画面已能交代动作时，一个固定机位就够了。

## 从一句话到两个镜头

“拿走堆在上面的任务，才有余力做重要的事。”用同一个橙色纸盒承接两镜。第一镜交代它承受的重量，第二镜靠近，看盒盖如何恢复。

| 成片时间 | 画面 | 切镜与衔接 |
| --- | --- | --- |
| 0–2.4 秒 | 平视中景。三只灰盒落在橙盒上，盒盖沿折痕下弯。 | 收尾留出朝前的折角，让下一个镜头接得上。 |
| 2.4–4.8 秒 | 同侧近景。灰盒向右滑出，盒盖弹回，边缘轻晃后停稳。 | 靠近是为了看清回弹。折角朝向、倾斜方向和主光位置沿用上一镜。 |

这组分镜可直接运行。命令从安装后的 Skill 目录执行，仅需 Python 和 Pillow。

```bash
python3 scripts/native_gif.py plan --request examples/narration.json
```

每镜的 `direction` 都可省略。选用能帮助本镜的字段即可。

| 字段 | 写什么 |
| --- | --- |
| `framing` | 观众要看清的部位、景别和构图。写明近景里仍需保留的接触点。 |
| `camera` | 镜头固定、平移或推近，以及它跟随哪个动作。 |
| `material_motion` | 哪个部位先受力，哪个部位稍后响应，何处保持形状。 |
| `continuity` | 本镜需要看见的事实，例如手拿哪件道具、开口朝向、主光方向。每次请求都写出事实，模型单独收到这一镜。 |
| `cut_reason` | 记下在这里切换视角想让观众看见什么，只用于分镜计划。 |

## 材质怎样影响动作

先沿用选中的风格，只采用画里确实存在的材质。下面是动作写法，可按主体和接触方式改写。

| 材质 | 可观察的动作 |
| --- | --- |
| 纸艺 | 纸翼沿原折线抬起，薄尖端最后振一下。 |
| 瓦楞纸板 | 盒盖绕压线合上，两侧厚板挺直，边沿相碰时停住。 |
| 黏土 | 手指轻按时接触面变扁，手移开后留下浅凹。 |
| 毛毡 | 小动物急停时身体先稳住，长耳尖晚一步落下。 |
| 钩针织物 | 球被拿起时下半部垂坠，针目跟随轮廓伸展。 |
| 薄布 | 夹子先带走布角，斜向褶皱才从夹点传向自由边。 |
| 木偶 | 前臂围绕销钉转动，木纹在同一块木件上保持固定。 |
| 金属发条玩具 | 钥匙带动齿轮转过一格，机身轻颤，外壳轮廓稳定。 |

交界处并排看上一镜末帧和下一镜首帧，核对位置、方向、受力状态。再按正常速度观看，判断停顿与切点是否读得清楚。风格选择与主参考的用法见[风格指南](styles.md)。
